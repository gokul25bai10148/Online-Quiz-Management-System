# Online-Quiz-Management-System

### Overview

* A simple Java-based quiz application.
* Students can register, log in, and attempt quizzes.
* The system calculates scores and displays a leaderboard.

### Features

* Student registration and login.
* Multiple-choice questions with a timer.
* Automatic scoring and leaderboard.
* Basic admin panel.

### Technologies / Tools Used

* Java
* OOP Concepts
* ArrayList and Exception Handling
* Java Threads
* Git & GitHub

### Steps to Install and Run

* Install JDK 8 or above.
* Clone/download the GitHub repository.
* Open `QuizVerse.java` in a Java IDE.
* Compile using `javac QuizVerse.java`.
* Run using `java QuizVerse`.

### Instructions for Testing

* Test student registration and login.
* Start the quiz and check the timer.
* Try correct and incorrect answers.
* Check the final score and leaderboard.
* Test invalid inputs and login details.
