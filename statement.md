Problem Statement

Traditional quizzes can involve manual question selection, answer checking, and score calculation, which can take extra time. QuizVerse is developed to provide a simple system where students can register, log in, attempt quizzes, and get their scores automatically.

Scope of the Project

1. The project can be used for conducting simple multiple-choice quizzes.
2. Students can register, attempt quizzes, and view their scores.
3. An admin can view the available quiz questions.
4. The system can be extended in the future with a database, GUI, more quiz categories, and detailed performance reports.

Target Users

1. Students: Can register, log in, attempt quizzes, and view their scores.
2. Admin: Can log in and view the available quiz questions.
3. Teachers/Trainers: Can use the system as a basic platform for conducting practice quizzes.

High-Level Features

1. User registration and login.
2. Multiple-choice quiz with a time limit.
3. Randomized quiz questions.
4. Automatic score calculation.
5. Student leaderboard.
6. Basic admin panel.
