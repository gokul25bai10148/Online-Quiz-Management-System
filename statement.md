Problem Statement

Traditional quizzes can involve manual question selection, answer checking, and score calculation, which can take extra time. QuizVerse is developed to provide a simple system where students can register, log in, attempt quizzes, and get their scores automatically.

Scope of the Project
The project can be used for conducting simple multiple-choice quizzes.
Students can register, attempt quizzes, and view their scores.
An admin can view the available quiz questions.
The system can be extended in the future with a database, GUI, more quiz categories, and detailed performance reports.

Target Users
Students: Can register, log in, attempt quizzes, and view their scores.
Admin: Can log in and view the available quiz questions.
Teachers/Trainers: Can use the system as a basic platform for conducting practice quizzes.

High-Level Features
User registration and login.
Multiple-choice quiz with a time limit.
Randomized quiz questions.
Automatic score calculation.
Student leaderboard.
Basic admin panel.
